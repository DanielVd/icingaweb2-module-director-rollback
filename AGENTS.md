# Repository guidelines

- Base work on `main`, use a focused branch for each change, and open a pull request with a summary and the checks performed.
- Use Conventional Commits. Set the Git author to `Daniel Vedovato <daniel.vedovato@gmail.com>` for each commit created in this repository.
- Include this trailer on each commit:

  `Co-authored-by: Codex <267193182+codex@users.noreply.github.com>`

- Run the PHP syntax checks in the README before opening or updating a pull request that changes the module.
